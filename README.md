### Status legend

| Badge | Meaning |
|---|---|
| 🟢 Ongoing | Permanent free tier, no end date published |
| 🟢 Active | Running promotion or new-user credit |
| 🟠 Extended | The provider officially extended the deadline |
| 🔴 Ending soon | Ends within 3 days |
| ⚫ Ended | Expired or paused; kept for reference |

Dates are as published by the provider; when the official page gives no number we write "Not published" instead of guessing.

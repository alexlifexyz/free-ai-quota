### 状态说明

| 标记 | 含义 |
|---|---|
| 🟢 长期 | 长期免费档，未公布结束日期 |
| 🟢 进行中 | 正在进行的活动或新人额度 |
| 🟠 已延期 | 厂商官方宣布延长了截止时间 |
| 🔴 即将截止 | 3 天内结束 |
| ⚫ 已结束 | 已到期或已暂停，保留备查 |

日期以厂商公布为准；官方没有给出数字时写“未公布”，绝不猜测。

## 数据文件

| 文件 | 内容 |
|---|---|
| [`data/offers.json`](data/offers.json) | 数据源：网站公开数据 [freeai.alexai.top/offers.json](https://freeai.alexai.top/offers.json) 的镜像（每条含中英文） |
| [`data/offers.csv`](data/offers.csv) | 每条活动一行：结构化字段 + 英文文本（由 JSON 生成） |
| [`data/offers_zh.csv`](data/offers_zh.csv) | 同一 `slug` 的简体中文文本（由 JSON 生成） |

主要字段：`status`（`active`/`expired`）、`category`（`evergreen` 长期、`limited` 限时、`trial_credits` 新人额度、`subscriber` 订阅附赠）、`end_date`（`YYYY-MM-DD`，用于自动过期）、`card_required`、`region`、`source_url`（官方来源）、`last_verified`。每周通过 `python3 scripts/gen_readme.py --fetch` 同步：下载网站数据，重新生成 CSV 和上面的表格。
